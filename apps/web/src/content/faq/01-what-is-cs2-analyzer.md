# What is CS2 Analyzer?

CS2 Analyzer is a web application that can be used for free, by everyone. It serves multiple purposes, that can be utilized by players, coaches and analytics, such as:

- Single GOTV Demo Analyzer, in which you can:
    - Watch the 2D replay with live HUD, killfeed and scoreboard, including own [Rating System](/rating).
    - Review each player's game: won/lost opening duels, trade kills, deaths with unused nades, etc.
    - Check the game summary: executes, pushes, retakes, fights.
    - List the utility from the whole game: who, what nade, where thrown and what effects it had (flashed enemies and teammates, dealt damage).
    - Make notes for each round (drawings, arrows, textboxes and bookmarks) and export them to PDF, either in native, dark mode, or white mode dedicated for printing.
- Multi-demo analyzer, in which you can:
    - Watch "aggregated" rounds, which show team or player habits: paths they usually take (including ratio-based frequencies), grenades they throw and how often, what they do mid-rounds (executes, fights, pushes). You can select these based on T/CT side and economy (pistol, eco, force, full).
    - Wiew multiple demos at once, switching between them easily through tabs - looking at the particular round, you may use all functionalities of the "single demo" Analyzer.
- Playbook, used to collect your own analyses and strats:
    - Create multiple strat-books per map - there is no limit!
    - Export snapshots from single/multi-demo Analyzer that you can use later as a summary of already analyzed, "saved for later" rounds or matches.
    - Prepare your own strats using multiple kinds of tools: pawns for CT/T, grenade markers (icon/effect), YouTube/imgur link attachment, drawing tools and a textbox.
    - Export PDFs from playbooks - all information you need in one place, ready to be printed or shared.

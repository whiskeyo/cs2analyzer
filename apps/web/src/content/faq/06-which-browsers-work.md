# Which browsers work?

I have access to Windows and Linux PCs, so I tested the most popular browsers by hand and I can say that all Chrome, Edge, Opera (and probably other Chromium-based browsers), Firefox work well. I am not sure about Safari, but I guess it should work.

If you want to use all features of the website, such as caching demo paths from your PC, then I would suggest using one of Chromium-based browsers: Chrome, Edge or Opera.
